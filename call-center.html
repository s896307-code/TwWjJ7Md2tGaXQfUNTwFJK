  • 工時上限每週正常工時上限 40 小時;加班需事前簽核,單月加班時數不超過 46 小時(依勞基法規定)。

問題回報

等級定義回報時限處理時限
P1 緊急系統全面中斷、大量客訴、資安或個資疑慮15 分鐘內1 小時內啟動應變
P2 高影響服務但有替代方案、個別重大客訴(如退款爭議)30 分鐘內4 小時內
P3 中一般操作問題、流程疑義、非緊急客訴當班內24 小時內
P4 低建議事項、優化提案、非急迫性回饋每日彙整納入週會討論
  1. 發現並登錄問題客服代表
    於問題回報表填寫工單編號、時間、客戶資訊、問題描述,並初步判斷嚴重度。
  2. 分級通報當班全員
    P1 / P2 需立即口頭告知值班組長並同步書面記錄;
    P3 / P4 於系統登錄即可,無需中斷現場工作。
  3. 組長評估與處理值班組長
    可自行處理者當場處理並記錄結果;超出權限或跨部門者,依聯絡矩陣上呈。
  4. 主管介入與協調客服主管
    P1 / P2 由主管設定 SLA、協調 IT / 產品 / 物流等相關部門,必要時對外發出客戶溝通稿。
  5. 結案與回覆客戶承辦人
    處理完成後回覆客戶、更新工單狀態;屬常見問題者同步更新知識庫。
  6. 事後覆盤P1 / P2 限定
    24 小時內召開簡短檢討會議,產出根因與改善行動,列入下次日報追蹤。
